# 水锤效应

水锤效应（也叫水击，Water Hammer）

一句话概括：**封闭管道里流动的液体，流速突然变化，依靠液体惯性产生来回震荡的压力冲击波，像锤子反复敲打管道**

## 原理

水流有质量、有惯性。当阀门猛地关掉 / 水泵突然停机，前面的水瞬间停住，后面的水还在往前冲，动能瞬间转为巨大压力；这个压力波会以接近水中声速沿管道来回反射，反复撞击管壁，你就会听到水管 “哐、哐” 的撞击声

## 两种类型

1. **正水锤（破坏力最大）**：快速关阀，压力急剧飙升，可达正常压力数倍到几十倍，容易爆管、打坏阀门
2. **负水锤**：突然开阀 / 停泵，局部形成真空负压；负压会让管道瘪塌，真空消失后水回流撞击，二次产生冲击

> ✅生活例子：家里快速关闭洗衣机进水电磁阀，水管 “咚咚” 响，就是典型水锤。

## 主要危害

- 瞬时高压：爆管、法兰接头漏水、阀门密封损坏
- 管道剧烈震动，支架松动脱落
- 水泵叶轮、轴承损坏，严重时水泵反转
- 负压阶段：管道内形成真空，吸入空气，空气泡会进一步放大水锤冲击

## 工程上的解决办法

1. **慢关阀门**：延长启闭时间，避免流速突变（最简单）
2. **加装水锤吸纳器（水锤消除器）**：吸收压力冲击波，家装、消防常用
3. **缓闭止回阀**：水泵出口标配，防止停泵水回流冲击
4. **稳压罐 / 气囊罐**：利用气体弹性缓冲压力
5. 管道高点安装排气阀，排掉管内空气；降低管道流速、适当放大管径

::: tip 补充小知识
水锤不只限于水，油、化工液体等所有管道流体都会产生；甚至**可以利用水锤效应做水锤泵，不用电，把低处水打到高处**。
:::
